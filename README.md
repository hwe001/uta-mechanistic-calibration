# uta-mechanistic-calibration

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23057564.svg)](https://doi.org/10.5281/zenodo.23057564)

Identifiability and calibration of a uteroplacental transmission-line model against routine uterine-artery Doppler
indices (PI, S/D). Code, solver adapter, validation and figure scripts accompanying the manuscript

> "What can routine uterine-artery Doppler tell us about uteroplacental mechanism? Identifiability and calibration of a
> transmission-line model" (submitted to *Computer Methods and Programs in Biomedicine*).

## What is and is not new

The forward model is the solver of Clark et al. (Placenta 2018;66:74-81), included unmodified in `external/` under its
own Apache 2.0 licence. This repository adds the audit and validation workflow around it:

| Component | Files |
|---|---|
| Solver adapter (modern NumPy, waveform metrics) and regression test | `code/solver_adapter.py`, `code/test_solver_adapter.py` |
| Cohort audit | `code/uta_data_audit.py` |
| Local and global identifiability (Jacobian, synthetic recovery, Sobol) | `code/identifiability_analysis.py`, `code/pilot_sensitivity.py`, `code/extended_analysis/sobol.py` |
| Statistical benchmark (mixed-effects) | `code/benchmark_fit.py` |
| Surrogate lookup grids with validated interpolation | `code/mechanistic_calibration.py` |
| One-dimensional mechanistic calibration (radial, uterine, arcuate, distal resistance, A-V shunt) | `code/mechanistic_calibration.py`, `code/extended_analysis/extended_mech.py` |
| Bounds-robustness study | `code/bounds_robustness.py` |
| Woman-level grouped cross-validation and solver-free controls | `code/woman_level_validation.py`, `code/extended_analysis/control_cv.py` |
| Matched-PI (effective dimension) and S/D out-of-sample checks | `code/extended_analysis/manifold.py`, `sd_check.py`, `sd_individual.py` |
| Figures | `code/generate_figures.py`, `code/extended_analysis/make_figs.py` |

## Data

The clinical workbook is not distributed (institutional data governance). A simulated dataset with the same columns is
provided so the scripts can be run end to end (`data/synthetic/`, generated by `code/make_synthetic_dataset.py`); its
results are illustrative only. See `data/README.md`. Examination-level output files (containing patient identifiers or
dates) are also withheld and are regenerated by the scripts.

## Run

Python 3.11+, NumPy, pandas, SciPy, statsmodels, scikit-learn, Matplotlib, openpyxl, SALib (see `environment.yml`).

```bash
python code/uta_data_audit.py --input data/synthetic/UtA_Doppler_Synthetic_Example.xlsx --output results/data_audit
python code/benchmark_fit.py --input data/synthetic/UtA_Doppler_Synthetic_Example.xlsx --output results/longitudinal_benchmark
python code/mechanistic_calibration.py --repo external/network-wave-transmission-master --input data/synthetic/UtA_Doppler_Synthetic_Example.xlsx --output results/mechanistic_calibration
python code/woman_level_validation.py --input data/synthetic/UtA_Doppler_Synthetic_Example.xlsx --grid results/mechanistic_calibration/solver_lookup_grid.csv --repo external/network-wave-transmission-master --output results/woman_level_validation
```

The extended analyses read `UTA_DATA` (path to the workbook) and write to the current directory; run them from
`results/extended_analysis/`:

```bash
cd results/extended_analysis
python ../../code/extended_analysis/other_axes.py
python ../../code/extended_analysis/manifold.py
python ../../code/extended_analysis/extended_mech.py     # needs the validation outputs above
python ../../code/extended_analysis/control_cv.py
python ../../code/extended_analysis/sobol.py
```

All scripts are seeded; seeds and versions are recorded in the per-folder metadata files.
