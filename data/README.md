# Data

The clinical workbook (`UtA_Doppler_Cleaned_Dataset_Anonymous.xlsx`) is **not** distributed: the data are held by the
Chongqing Health Center for Women and Children under institutional data-governance restrictions. To reproduce the
analyses on the real data, place the workbook in this folder (it is git-ignored) or set the environment variable
`UTA_DATA` to its path.

`synthetic/UtA_Doppler_Synthetic_Example.xlsx` is a simulated dataset with the same columns, generated by
`code/make_synthetic_dataset.py`. It lets the audit, benchmark, calibration and validation scripts run end to end.
Its results are illustrative and are not the results reported in the paper.

Column definitions: see the data dictionary in the paper's supplementary material.
